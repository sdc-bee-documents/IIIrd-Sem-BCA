## 📚 Unit-Wise Index

### 📘 Unit 1: Foundations & Control Structures

Fundamental syntax, JVM architecture, basic data types, and primary flow-control logic.

- [ ] **Chapter 1 - Introduction to Java:** [Read Notes]([](./Unit - 1/Chapter 1 - Introduction to Java.pdf))
  - History, evolution, and features of Java (simple, secure, portable, robust)
  - Java Virtual Machine (JVM), JDK vs. JRE architecture
- [ ] **Chapter 2 - Overview of Java Language:** [Read Notes](./Unit-1/Chapter-2-Overview-of-Java-Language.md)
  - Structure of a Java program, class declaration, `main()` signature breakdown
  - Source file naming conventions and bytecode compilation
- [ ] **Chapter 3 - Constants, Variables and Data Types:** [Read Notes](./Unit-1/Chapter-3-Constants-Variables-and-Data-Types.md)
  - Primitive data types, memory footprints, and default values
  - Type conversion, type casting, identifiers, and literals
- [ ] **Chapter 4 - Operators and Expressions:** [Read Notes](./Unit-1/Chapter-4-Operators-and-Expressions.md)
  - Arithmetic, relational, logical, bitwise, assignment, and ternary operators
  - Operator precedence, associativity, and expression evaluation
- [ ] **Chapter 5 - Decision Making and Branching:** [Read Notes](./Unit-1/Chapter-5-Decision-Making-and-Branching.md)
  - Simple `if`, `if-else`, nested `if`, and `else-if` ladders
  - The `switch-case` construct and fall-through rules
- [ ] **Chapter 6 - Decision Making and Looping:** [Read Notes](./Unit-1/Chapter-6-Decision-Making-and-Looping.md)
  - Entry-controlled (`while`, `for`, enhanced `for-each`) vs. exit-controlled (`do-while`) loops
  - Jumps in loops: `break`, `continue`, and labeled loops

---

### 📗 Unit 2: Object-Oriented Principles & Collections

Core object-oriented abstractions, state encapsulation, arrays, and standard string utilities.

- [ ] **Chapter 7 - Classes, Objects and Methods:** [Read Notes](./Unit-2/Chapter-7-Classes-Objects-and-Methods.md)
  - Defining classes, field encapsulation, and object instantiations
  - Constructors (default, parameterized, copy) and constructor overloading
  - Method signatures, return semantics, and method overloading
  - `this` keyword, static variables, and static methods
- [ ] **Chapter 8 - Arrays, Strings and Vectors:** [Read Notes](./Unit-2/Chapter-8-Arrays-Strings-and-Vectors.md)
  - Single and multi-dimensional array memory allocations
  - String manipulation via `String`, `StringBuffer`, and `StringBuilder`
  - Dynamic resizing and element storage using `Vector`

---

### 📙 Unit 3: Advanced Abstractions, Concurrency & Resilience

Contract-driven architecture, modularity, parallel task execution, and fault management.

- [ ] **Chapter 9 - Interfaces: Multiple Inheritance:** [Read Notes](./Unit-3/Chapter-9-Interfaces-Multiple-Inheritance.md)
  - Defining, implementing, and extending interfaces
  - Achieving multiple inheritance and runtime polymorphism
- [ ] **Chapter 10 - Packages: Putting Classes Together:** [Read Notes](./Unit-3/Chapter-10-Packages-Putting-Classes-Together.md)
  - Java API package taxonomy (`java.lang`, `java.util`, `java.io`)
  - User-defined packages, access protection levels, and `import` semantics
- [ ] **Chapter 11 - Multithreaded Programming:** [Read Notes](./Unit-3/Chapter-11-Multithreaded-Programming.md)
  - Thread life cycle (New, Runnable, Running, Blocked, Terminated)
  - Subclassing `Thread` vs. implementing `Runnable`
  - Thread priorities and inter-thread synchronization
- [ ] **Chapter 12 - Managing Errors and Exceptions:** [Read Notes](./Unit-3/Chapter-12-Managing-Errors-and-Exceptions.md)
  - Checked vs. Unchecked exceptions
  - `try`, `catch`, `finally`, `throw`, and `throws` mechanics
  - Crafting custom user-defined exceptions

---

### 📕 Unit 4: GUI, Applets & Persistent Storage

Client-side visuals, legacy browser components, and local stream/file manipulation.

- [ ] **Chapter 13 - Applet Programming:** [Read Notes](./Unit-4/Chapter-13-Applet-Programming.md)
  - Local vs. remote applets, security model
  - Applet lifecycle (`init`, `start`, `paint`, `stop`, `destroy`)
  - HTML embedding using the `<applet>` tag
- [ ] **Chapter 14 - Graphics Programming:** [Read Notes](./Unit-4/Chapter-14-Graphics-Programming.md)
  - The `Graphics` class coordinate space
  - Drawing lines, rectangles, circles, ellipses, polygons, and text
  - Color control and font customization
- [ ] **Chapter 15 - Managing Input/Output Files in Java:** [Read Notes](./Unit-4/Chapter-15-Managing-Input-Output-Files-in-Java.md)
  - Concept of byte streams (`FileInputStream`, `FileOutputStream`)
  - Character streams (`FileReader`, `FileWriter`)
  - Sequential vs. random file access via `RandomAccessFile`
